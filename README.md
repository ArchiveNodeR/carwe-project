# 🚗 CarWe — Подбор и обслуживание автомобилей в Молдове

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

Одностраничный лендинг для автомобильного сервиса **CarWe**. Сайт помогает клиентам подобрать авто с пробегом, купить новую машину из салона без наценок и записаться на плановое ТО.

Дизайн выполнен в современном **Dark Theme** стиле с ярким оранжевым акцентом, плавными анимациями и адаптивной версткой.

## ✨ Особенности проекта

- 🎨 **Современный UI/UX** — тёмная тема, glassmorphism (стеклянный навбар), фоновые сетки и мягкое свечение элементов.
- 📱 **Адаптивность** — корректное отображение на смартфонах, планшетах и десктопах (благодаря Tailwind CSS).
- 🗂 **Интерактивные табы** — переключение между направлениями (Авто с пробегом, Новые из салона, Обслуживание).
- 📝 **Умная форма заявки** — при выборе «Запись на сервис» поля «Бюджет» и «Желаемая марка» скрываются, уступая место выбору вида работ.
- 🖼 **Оптимизированные фото** — карточки автомобилей с эффектом масштабирования при наведении.

## 🛠 Технологии

- **HTML5** — семантическая разметка.
- **Tailwind CSS v4** — стилизация, кастомные токены темы (цвета, шрифты), адаптив.
- **JavaScript (Vanilla)** — логика переключения табов и мобильного меню.
- **Google Fonts** — Space Grotesk, Inter, JetBrains Mono.
